# 蛛蛛 Zhuzhu

Паук плетёт сеть. Я учу китайский. Принцип примерно один: нитка за ниткой,
пока не получится что-то, что держит.

Тренажёр по HSK Standard Course семь книг, 106 уроков, 2337 слов. Кроме
словаря в каждом уроке лежит текст с переводом, разбор грамматики и
упражнения с проверкой. Прогресс живёт в браузере, а если войти ещё и
синхронизируется между устройствами.


## Откуда данные

Слова, тексты и грамматика — из учебников HSK Standard Course. Слова
нового HSK 3.0 (программа 2025 года, `src/data/hsk3-2025.js`) взят из
[becky82/mteh](https://github.com/becky82/mteh), пиньинь к нему расставлен
[pinyin-pro](https://github.com/zh-lx/pinyin-pro) (MIT) и может ошибаться в тонах.
