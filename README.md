# 蛛蛛 Zhuzhu

Паук плетёт сеть. Я учу китайский. Принцип примерно один: нитка за ниткой,
пока не получится что-то, что держит.

Тренажёр по HSK Standard Course — семь книг, 106 уроков, 2337 слов. Кроме
словаря в каждом уроке лежит текст с переводом, разбор грамматики и
упражнения с проверкой. Прогресс живёт в браузере, а если войти — ещё и
синхронизируется между устройствами.

## Запуск

```bash
npm install
npm run dev       # localhost, горячая перезагрузка
npm run build     # сборка в dist/
npm run preview   # посмотреть, что собралось
```

## Что где лежит

`index.html` — все экраны сразу, переключаются через `showView()`.

`src/main.js` — сборка всего воедино и обработчики.
`src/state.js` — прогресс, стрик, localStorage.
`src/navigation.js` — роадмап, уроки, крошки.
`src/progress.js` — интервальные повторения: когда слово вернётся.

Четыре режима тренировки: `cards.js`, `quiz.js`, `match.js`, `writing.js`.
Учебниковая часть: `exercise.js`, `content-views.js`.

`src/data/bookN.js` — слова. `bookN-content.js` — тексты, грамматика,
упражнения. `data/meta.js` — какие книги готовы и какого они уровня HSK.

Книга 4下 пока пустая. Появятся `book4b.js` и `book4b-content.js`, в
`meta.js` встанет `ready: true` — и она сама зажжётся в роадмапе.
